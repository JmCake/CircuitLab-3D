# 实验课程与器材规划

## 1. 学校实验室式工作台

采用三维实验桌与独立仪器陈列，而不是将应用等同于某一块面包板。优先提供可调直流稳压电源、接线柱、指针/数字表、电阻箱与连接导线，使学生理解**接线位置、仪表串并联、量程选择及读数**；面包板作为另一个可选器材出现。

## 2. 器材实施层次

| 器材 | 3D 交互要求 | 电学模型 | 计划阶段 |
| --- | --- | --- | --- |
| 直流稳压电源 | 面板、旋钮、正负接线柱、电压标识 | 独立电压源，适当限流/内阻 | P1–P3 |
| 固定电阻 | 阻值标识、双端子 | 理想线性电阻 | P1–P3 |
| 开关 | 可拨动、开闭状态明显 | 有限导通电阻/断开等效 | P1–P3 |
| 导线 | 插头、曲线、端子吸附、拔插 | 同节点连接（可扩展线阻） | P1–P3 |
| 电流表 | 接线柱、量程/读数显示 | 串联测量，低内阻 | P1–P4 |
| 电压表 | 接线柱、量程/读数显示 | 并联测量，高内阻 | P1–P4 |
| LED | 极性识别、亮灭/亮度 | 明确标注近似的二极管模型，后续非线性 | P4–P5 |

## 3. 教学实验安排

### E01 欧姆定律验证（MVP）

**器材：** 直流电源、开关、固定电阻、电流表、电压表、导线。**学生操作：** 连接串联电流表，将电压表并联在被测电阻两端；改变电压或电阻并记录 U、I、R。**验证：** 依据真实连接关系判断测点是否正确，比较 U/I 与电阻标称值，允许仪表内阻造成的已知偏差。

### E02 串联电阻与分压

**器材：** 两个以上电阻、电源、开关、电压表、电流表。**操作：** 搭建串联网络、测量各端电压。**验证：** 支路电流相同，分压与各电阻阻值相关，总电压与分压一致（容差内）。

### E03 并联电阻与分流

**器材：** 多个电阻、仪表及电源。**操作：** 连接并联支路，逐支路测量。**验证：** 各支路端电压一致、总电流等于支路电流之和。

### E04 基尔霍夫定律（KCL/KVL）

**器材：** 可组成多回路网络的电阻、电源、电流表、电压表。**操作：** 自由布线并测量节点、回路。**验证：** 通过实际数值检查电流守恒与回路电压平衡，而非只比对模板接线。

### E05 LED/小灯泡亮度与限流（非线性阶段）

**操作：** 改变限流电阻/电压，观察亮灭与亮度。**验证：** 极性、限流以及功耗状态；明确区分简化模型与真实器件响应。

### E06 RC 充放电（后续）

**器材：** 电源、电阻、电容、开关和计时/曲线工具。**验证：** 指数变化趋势、时间常数与测量曲线；要求仿真器支持暂态。

## 4. 自由搭建和教学模式的共同约束

- 同一电路域模型，不允许教学模式中用预设答案代替求解结果。
- 教学步骤通过连接规则、计算值及容差判定，不能只凭元件摆在正确位置。
- 教师后续可增加新的实验模板，但无需修改仿真引擎。
- 实验文档须标注电学模型假设，例如理想线性电阻、有限仪表内阻和简化 LED 模型。
