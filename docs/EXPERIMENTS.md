# 实验课程与器材规划

> 更新（2026-11-13）：以下器材与实验已进入实际可运行版本。E01 具有完整教学闭环与浏览器验证；E02–E06 已实现示范器材、真实求解与步骤检查。未完成的物理细节见 [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md)。

## 1. 学校实验室式工作台

采用三维实验桌与独立仪器陈列，而不是将应用等同于某一块面包板。优先提供可调直流稳压电源、接线柱、指针/数字表、电阻箱与连接导线，使学生理解**接线位置、仪表串并联、量程选择及读数**；面包板作为另一个可选器材出现。

## 3. 教学实验安排

### E01 欧姆定律验证（MVP，已实现并验证）

**器材：** 直流电源、开关、固定电阻、电流表、电压表、导线。**学生操作：** 连接串联电流表，将电压表并联在被测电阻两端；改变电压或电阻并记录 U、I、R。**验证：** 依据真实连接关系判断测点是否正确，比较 U/I 与电阻标称值，允许仪表内阻造成的已知偏差。

**实现结果：** 示范接线下电流表约 5.999 mA、电压表约 5.998 V；记录后由 U/I 计算 R≈999.9 Ω，五步教学检查全部通过。真实鼠标拖线、撤销/重做、数据记录与刷新恢复均已验证。

### E02 串联电阻与分压（已实现）

**器材：** 两个以上电阻、电源、开关、电压表、电流表。**操作：** 搭建串联网络、测量各端电压。**验证：** 检查两电阻电流一致、U₁+U₂ 接近电源端电压以及 U₁/U₂ 与 R₁/R₂ 的比例。

### E03 并联电阻与分流（已实现）

**器材：** 多个电阻、仪表及电源。**操作：** 连接并联支路，逐支路测量。**验证：** 检查各支路端电压一致、干路电流接近支路电流之和，并有记录步骤。

### E04 基尔霍夫定律（KCL/KVL，已实现）

**器材：** 两条并联支路的两只电阻、电源、开关、干路电流表、电压表。**操作：** 测量干路电流、节点电压，并把电流表移到不同支路测量。**验证：** 示范接线使用真实并联网络，检查多条有电流的支路、仪表存在以及记录数量；求解全程按真实拓扑进行。

### E05 LED/小灯泡亮度与限流（已实现）

**器材：** 电源、开关、限流电阻、LED、电流表，以及并联在 LED 两端的电压表。**操作：** 改变限流电阻/电压，观察亮灭与亮度，同时记录 LED 工作点。**验证：** 检查 LED 极性、正向电流和推荐范围；三维封装光晕与相对亮度由实际电流驱动。小灯泡可通过自由搭建点亮，亮度由耗散功率驱动。

### E06 RC 充放电（已实现核心）

**器材：** 电源、电阻、电容、开关和计时/曲线工具。**验证：** 后向欧拉逐步求解，曲线显示电容端电压；检查 63.2% 目标附近进度和时间常数 τ=RC。低帧率下仿真时间可能慢于墙钟，UI 明确显示“仿真时间”。

## 4. 自由搭建和教学模式的共同约束

- 同一电路域模型，不允许教学模式中用预设答案代替求解结果。
- 教学步骤通过连接规则、计算值及容差判定，不能只凭元件摆在正确位置。
- 教师后续可增加新的实验模板，但无需修改仿真引擎。
- 实验文档须标注电学模型假设，例如理想线性电阻、有限仪表内阻和简化 LED 模型。
