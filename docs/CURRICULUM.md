# 大学电路基础实验体系

课程边界：当前可操作范围是直流线性网络、分段线性 LED 与一阶 RC。学习顺序参考 [MIT 6.002 课程讲义](https://ocw.mit.edu/courses/6-002-circuits-and-electronics-spring-2007/pages/lecture-notes/)，不将尚未实现的交流、RLC、运放等内容列为已完成实验。

| 实验 | 先修知识 | 可操作学习目标 | 主要验证依据 |
| --- | --- | --- | --- |
| E01 欧姆定律 | 电势、电流、线性电阻 | 串联电流表、并联电压表，比较 U/I 与 R | 有效回路、电流一致性、测量记录 |
| E02 串联分压 | 欧姆定律、KVL | 测量分压比、电压代数和 | 实际支路电流与电阻电压 |
| E03 并联分流 | 欧姆定律、KCL | 公共节点、电流分配 | 支路端电压与干路电流之和 |
| E04 基尔霍夫定律 | 有向支路与节点 | 检查节点电流残差与全网功率平衡；根据统一节点电势核查回路电压 | 独立网表守恒审计及记录 |
| E05 LED 限流 | 非线性与极性 | 比较正反向、限流电阻、颜色对应电流上限 | 分段线性解与相应颜色的安全阈值 |
| E06 RC 充放电 | 电容、微分方程 | 观察充放电、改变 R/C、导出时序数据 | 后向欧拉子步积分、实际墙钟、解析解误差回归 |
| E07 戴维南等效 | 线性有源二端网络 | 改变负载，比较原网与等效响应 | 开路求解 + 独立源置零 + 测试源法 |
| E08 叠加定理 | 线性性、符号约定 | 核查各源贡献的代数和；理解功率不能叠加 | 每个独立源单独作用的实际求解 |
| E09 最大功率传输 | 戴维南等效 | 记录不同负载，验证 RL≈Rth 附近最大功率 | 负载功率、理论曲线、不同工作点记录 |

## 科学约定

- 求解器内部统一使用 V、A、Ω、F、s；UI 按量级显示 mA、mW、µF、ms。
- 电源电流、功率的正值表示向外提供；其他两端器材电流由目录首端指向末端，功率采用吸收为正。电容放电可以出现负功率。
- 三端变阻器显示的电流为 A→W，功率为 A–W 与 B–W 两段之和；节点审计使用全部三端电流。
- 仪表并非理想：电流表 0.1 Ω、电压表 10 MΩ；理论比较保留其负载效应。
- 戴维南与叠加只用于线性直流阻性网络；含 LED 或电容时不显示该等效结果。抑制电压源是置零电动势、保留内阻，而非关闭输出形成开路。
- RC 图中“名义 RC”不含仪表与电源内阻；具体解析测试包含其影响。断开开关并不等价于经原串联 R 放电；放电按钮将电源设为 0 V 并保留内阻。
- 数值积分上限为 2 ms，曲线采样 20 ms。比步长更快的过程准确度受限。后台冻结、明显计算积压时暂停；不把计算时间与电路物理时间混为一谈。
- 电源仍是有限内阻的教学模型，没有恒流环或实际熔断/热保护；超额定功率的匹配计算只作数学参考。

## 实验报告与自由搭建

每个实验先说明端口极性、拓扑、元件参数和模型假设，再记录工作点。E07–E09 的多组记录必须有不同数值，重复记录同一点不计为新的工作点。CSV 与工程 JSON 可导出，暂态可另行导出时间—电容电压 CSV。

自由搭建可组合全部 11 类器材，不要求固定坐标。需要自行检查回路和量程。当前工作点 CSV 记录主要电压/电流；多支路详细值在数值分析表中查看，尚未将全部支路时序作为统一实验报告归档。

后续课程：交流相量与阻抗、RLC/谐振、示波器与函数发生器、运放、完整二极管/晶体管模型。这些需要独立求解器扩展及解析/SPICE 对照后再开放，当前未实现。
