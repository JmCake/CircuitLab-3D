# 八项课堂实验与科学约定

课程顺序来自用户提供的河北农业大学课堂目录；学校现用指导书、原理图与仪器型号尚未提供。平台采用可验证的教学电路，不宣称复原学校原装设备。

| 实验 | 实际操作与验证依据 |
| --- | --- |
| E01 线性与非线性伏安特性验证 | 更换实际三维电阻/灯泡模块，改变电源，记录多点伏安曲线；重复点不计为新点，固定器件参数分组 |
| E02 电位、电压的测定及电位图的绘制 | A/B/C/D 对应真实端口；更换参考点只改变显示基准，固定纵轴展示电位平移，U_BC 不变 |
| E03 验证基尔霍夫定律 | 约定 AM、R1、R2、VM 支路正方向，核查带符号电流和 PS/SW/AM/R 的回路电压 |
| E04 线性电路叠加性和齐次性验证 | 两源共同作用、单独作用和同比变化的实际求解记录；保留其余参数与接线，不用全零响应冒充验证 |
| E05 验证戴维南定理 | 两负载伏安法估参，与开路求解、独立源置零后的测试源法对照；计入仪表负载 |
| E06 最大功率传输条件研究 | 同一有源网络改变负载，记录匹配点与两侧真实功率；不同电源或网络的记录不能拼为一组 |
| E07 三相交流星形电路连接的测量 | 检查真实星形接法，记录对称负载和同一不对称负载的有中线/无中线结果 |
| E08 三相交流电路三角形连接的测量 | 检查真实三角形接法，记录对称/不对称负载，比较电流的相量差与有效值 |

## 模型和符号

- 内部使用 V、A、Ω、W、s；交流相量的模为有效值，采用 exp(jωt) 约定。默认 50 Hz、24 V 相电压，ABC 相序为 0°、−120°、+120°；ACB 反转相序。
- 直流与三相单频相量使用独立求解流程，共用端口与导线形成的电气节点。三相当前支持电阻、闭合开关、AC/DC 电压表和电流表；不包含 RLC、电机和非线性交流波形。
- 直流电源和三相源各相含 0.2 Ω 内阻；电流表 0.1 Ω，电压表 10 MΩ。量程和 AC/DC 模式不匹配会阻止记录。
- 直流两端元件电流以目录首端到末端为正，吸收功率为正；电源读数以向外提供为正。三相电压/电流表显示有效值，无直流极性正负含义；交流审计使用复数端口电流与有功功率，不能把幅值直接代数相加。
- 小灯泡采用稳态热电阻经验模型，额定热态电阻 R_hot 与额定功率确定额定点；R_cold = 0.1 R_hot，R(U) = R_cold + (R_hot − R_cold)(|U|/U_rated)^0.55。Newton 迭代必须收敛后才显示结果。不包含热惯性、实测灯丝标定或烧毁。
- 对称星形负载可比较 U_L≈√3U_P、I_L≈I_P；对称三角形负载可比较 U_L≈U_P、I_L≈√3I_P。微小偏差包含源内阻和测量负载。不对称时按真实节点相量计算，不套用对称电流比例。
- 中性线是否接通按实际接线与开关连续性判断；不对称星形断中线后重新求解负载中点位移，不保持各相负载电压恒定。
- 叠加中令其余电压源电动势为零并保留内阻；关闭输出是开路，不能替代置零。功率不满足叠加。
- 不将断电零读数、重复点或改变了其他网络参数的记录用于完成相应实验判定。测量 CSV 保存当前实验所需字段，工程 JSON 保留参数、接线、记录及电位参考点。

## 自由搭建与边界

自由搭建保留旧的 LED、面包板和 RC 能力。LED 为分段线性近似；RC 使用 2 ms 后向欧拉子步、20 ms 采样，后台冻结。RC 时域与交流相量不能混算。

当前没有线缆动力学、器材间碰撞、真实限流保护与热损坏；没有完整半导体/电机/变压器模型、SPICE 精度认证及硬件 GPU 基准。数据和近似模型不构成真实硬件安全操作保证。
