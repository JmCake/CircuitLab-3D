# CircuitLab-3D｜三实验场景扩展方案（暂缓实施）

**状态：仅保留方案，不进行功能开发。**

本文件保留面包板实验室与综合电路实验箱两个未来扩展方向。现有自由实验台及已经完成的课程、仪器、接线、仿真、存档与发布流程均保持不变。只有在明确重新授权开发后，才启动建模和实现。

## 总体定位

一个 Web 3D 电路教学平台，提供面向不同使用者的三个独立实验场景：

| 场景 | 适用对象 | 教学重点 | 当前决定 |
| --- | --- | --- | --- |
| 自由实验台 | 大学电路基础课程及电工电子教学 | 独立仪器、自由接线、实验测量、数据分析 | 保留现有成果，不重构 |
| 面包板实验室 | 初学者、电子爱好者、创客 | 元件引脚插接、面包板布线、基础电子制作 | 仅保留方案 |
| 综合电路实验箱 | 高校《电路原理》《电路分析》实验课程 | 通过集成模块和外部端子完成定理验证 | 仅保留方案 |

顶部可采用简单的“自由实验台 / 面包板 / 实验箱”三段式场景入口；每个场景独立存档与恢复，切换不清空其他场景。

## 方案 A：3D 面包板实验室

以真实免焊面包板和 BBRouter 的操作体验为参考。先研究标准 400 孔、830 孔面包板的尺寸、孔距、电源轨断点与孔组内部连通规则，再选定首期规格。

- Three.js + React Three Fiber **代码程序化建模**：板体、孔位、金属触点、丝印及端子；对密集重复孔位采用实例化绘制。
- 用户可从器材库取电阻、LED、电容、二极管、芯片等，将**实际引脚**插入孔位，支持插拔、移动、跨孔摆放和跳线连接。
- 依据孔组与引脚接触关系生成真实电气网络，不将空间接触或视觉交叉等同于电气连接。
- 仿真计算、仪器显示、异常提示与数据记录复用主平台已有引擎。保存元件、孔位连接、器材参数和导线状态。
- 视觉上重视孔距、比例、细节和近距离可操作性；以实际浏览器运行截图和操作测试验收，而不是静态预览图。

**核心验收**：独立搭出电源—限流电阻—LED 回路，插错孔时不导通，修正接线后依据实际计算点亮；断开连接时恢复熄灭。首期不宣称具备未经实现的完整芯片仿真。

## 方案 B：综合电路分析实验箱

**外观基准为用户提供的真实绿色 PCB 铝合金手提实验箱照片**，不是重新设计一台通用实验装置。先做准确的面板布局图，再进行模型开发；最初状态不放导线。优先还原：

- 银色铝合金箱体、黑色独立线材收纳区、提手和卡扣。
- 绿色 PCB 的真实分区与密集白色电路丝印、模块名称、实验接线孔、状态灯、拨动开关和旋钮。
- 照片中多组红色数码管、右侧集中式调节控件与底部电源/测量端子。
- 支持顶视与局部放大，使电路标识清晰且接线柱容易操作。

功能上参考大学电路分析实验的实际课程：欧姆定律、基尔霍夫定律、叠加定理、戴维南与诺顿定理、最大功率传输等。逐步扩展受控源、负阻抗变换器、RC/RLC 等模块，**所有功能必须有真实电路模型和可核对的接线图**，不能用丝印或固定读数假装已经实现。

实验箱本体在三维场景中是一套器材，电气上应拆分为内部元件与外部端口组成的子电路，并接入已有的 MNA/暂态求解引擎。接线、开关与电位器操作驱动真实求解，显示屏与测量数据来自仿真结果。缺少确切原厂参数时应明确教学近似及其边界。

**核心验收**：按照箱面接线图完成一组基尔霍夫/叠加定理实验，改变内部电阻或外部导线后，电压表和电流表读数按电路计算同步变化；错误接线给出准确反馈。

## 技术与产品原则

1. 复用现有 React、TypeScript、Three.js、React Three Fiber、WebGL 2、端口 ID、导线、物理仿真、仪表组件和存档机制；不推翻原有项目。
2. 三个场景之间共用**电学计算核心**，各自有不同三维布局、器材组织和教学交互。
3. 新增场景应单独开发、单独验证后才合并；**先验证真实外观与关键交互，再扩展功能**。
4. 按用户真实照片和公开的器材资料整理参考，不接受偏离实物过大的简陋几何演示。
5. 质量验收包括程序化建模细节、操控准确性、电学结果、端口连接、普通集成显卡性能、浏览器回归、数据持久化和现有自由实验台不回退。
6. 不启动自动开发或发布，直到用户明确重新提出开发要求。

## 恢复开发时的建议顺序

第一轮：先查验参考器材，确定面包板规格、实验箱各分区的准确视觉方案和可测试的最小电路。第二轮：完成一套能真实运行的端口—接线—仿真闭环并进行视觉验收。第三轮：补充教学内容、更多仪器和实验模板，并进行完整回归测试。

本文件只描述目标和验收边界，不代表上述两个场景已经在正式版上线。
