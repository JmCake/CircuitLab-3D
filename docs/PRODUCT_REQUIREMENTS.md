# 产品需求与功能范围（PRD）

## 1. 面向谁、解决什么问题

**目标用户：** 大学电路类课程的学生与任课教师。首期以学生个人实验操作为主，教师用来布置、讲解、展示实验；暂不建设班级管理、在线考试或成绩后台。

**核心问题：** 常见二维仿真器适合验证电路原理，但难以训练学生对实验器材、接线柱、仪表量程与串并联接线的空间理解；纯三维场景又往往缺少可信的电气求解。项目将三维操作流程与真实计算结果连接起来。

**产品形态：** 桌面浏览器优先，支持 WebGL 2 的 Windows/macOS/Linux 浏览器；键鼠优先，触屏作为以后增强项。

## 2. 典型使用流程

1. 打开实验台，选择“教学实验”或“自由搭建”。
2. 从器材库拖入直流电源、开关、电阻/电阻箱、导线、电流表、电压表等器材。
3. 通过三维端子接线，导线自动吸附，避免漂浮接触导致电气连接状态不明确。
4. 调整电源和器材参数，闭合开关，观察电流、电压以及 LED/灯泡的反应。
5. 在实验模式下按步骤检查连接并记录数据，生成可导出的实验记录；自由模式不强制执行指导步骤。
6. 保存电路，重新打开后能恢复布局、连接及参数。

## 3. 五大核心需求

### F1 代码生成三维器材

- **首个可运行阶段必备**：实验桌、可调直流电源、开关、固定电阻、连接导线、电流表、电压表，以及必要的指示灯；每个端口具有稳定 ID、端口位置及电气意义。
- **后续必备扩展**：电容、滑动变阻器/电阻箱、小灯泡、面包板、更多规格 LED。
- 外观要求：能分辨器材类型、输入输出端子、正负极和量程标识；尺寸比例在同类实验器材间一致，不追求工业级 CAD 精度。
- 采用几何组合、曲面、TubeGeometry/CatmullRomCurve3、CanvasTexture 等代码生成几何、导线、刻度和标识。后续可选择性引入第三方素材，但不能让其成为核心运行依赖。

### F2 三维实验操作

- 相机：旋转、缩放、平移、重置与聚焦；操作器材时避免误触发相机拖拽。
- 器材：选中、拖拽、旋转、参数调整、放置约束、端子高亮；可删除、撤销、重做。
- 导线：从可连接端口开始，连接到另一端口；吸附成功时形成电气边；支持拔除、换接、路径可视化；禁止把仅仅视觉相交的导线算作连接。
- 仪表：电流表串联、电压表并联；接口接错时由拓扑模型判断并给出适当反馈。

### F3 真实电路逻辑

- 电气元件独立于三维 Mesh 存在；导线及元件端口共同构成电路图。
- 基础运算：欧姆定律、基尔霍夫电流/电压定律与 MNA；先支持稳定直流的线性电阻网络、理想/带内阻的电源、开关、仪表等效模型。
- 常见结构识别：开路/短路、串联/并联基础结构；复杂混联优先保证求解正确，教学标签识别能力逐步完善。
- 非线性器件（LED、灯泡）和电容暂态不直接宣称“完全真实”：早期可使用明确标注的近似模型，后续单独增加数值迭代及暂态求解。
- 检测浮置节点、不可求解、无效参数、零阻短路风险和模型不支持情况；以错误信息替代错误数值。

### F4 实时视觉与仪表反馈

- 回路状态变化或参数变化时触发重算，仪表显示对应电流或电压。
- LED 亮灭/亮度由电流结果驱动；灯泡亮度按功率映射并注明是否为简化模型。
- 预留导线高亮、电流方向提示、端子颜色、短路告警、参数说明。
- 不使用预置动画代替计算；出现求解失败时，明确显示“无法计算/连接错误”，不得保留误导性旧读数。

### F5 实验教学系统

- 实验目标、器材清单、文字指导、步骤状态和关键检查点。
- 学生可以手动完成接线，不强制系统自动生成正确电路。
- 记录参数、电压、电流、实验结论；支持本地保存与 CSV/JSON 导出。
- 验证方式优先采用拓扑约束与数值容差，不通过 3D 器材摆放位置判断电路是否正确。
- 自由搭建模式与教学模式共享建模、接线和求解核心，避免双套业务逻辑。

## 4. MVP（第一条完整功能闭环）

**目标实验：** 直流电源—开关—电阻串联，增加电流表串联和电压表并联，完成欧姆定律的测量与记录。MVP 要求器材能自由放置、导线连接、断开、读数更新、基础错误提示及数据保存。

**MVP 不要求：** 完整 SPICE 精度、交流电路、示波器、三相电、物理电磁场模拟、多人协作、课程成绩后台、手机端原生应用、AI 助教或真实元件三维碰撞模拟。

## 5. 非功能需求

- **稳定性**：无效连接不能导致页面崩溃或死循环；仿真遇到奇异矩阵有可理解反馈。
- **性能**：以普通带集成显卡的笔记本、1080p 浏览器为主要测试条件；首期性能目标建议为常见教学回路中交互流畅，具体 FPS/模型数量阈值在原型测试后冻结。
- **可用性**：中文界面优先，线缆选择、可连接端口、高亮与错误反馈明确。
- **可维护性**：渲染、编辑器、领域模型、求解器、实验教程相互隔离。
- **可移植性**：初期纯前端、本地运行和静态部署可用；不强制用户登录。

## 6. 验收的最小用户故事

- 学生能从零搭出欧姆定律实验回路，而不依赖脚本预设结果。
- 学生把电压从 5V 改为 10V，保持 1kΩ 电阻时，理想线性电路计算电流由 5mA 变为 10mA。
- 学生断开开关，回路电流归零；电压表读数取决于其实际跨接节点，不统一强行归零。
- 学生接错电流表或造成电源短路，系统给出有意义的提示且不显示无限电流。
- 学生可以保存并重新打开实验，原有接线和参数一致。
