# 八项课程对齐

依据：用户提供的河北农业大学课堂实验目录。未取得该校实验指导书、原理图和实验箱型号，因此按目录实现可验证的教学电路，不宣称复原学校现用装置。

1. 线性与非线性伏安特性验证
2. 电位、电压的测定及电位图的绘制
3. 验证基尔霍夫定律
4. 线性电路叠加性和齐次性验证
5. 验证戴维南定理
6. 最大功率传输条件研究
7. 三相交流星形电路连接的测量
8. 三相交流电路三角形连接的测量

实施顺序：独立交流相量与非线性灯泡模型 → 八项接线与教学验证 → 按实验显示器材和测量面板 → 程序化三相电源 → 数值、浏览器和视觉验收 → 提交。保留旧实验及存档兼容能力，主目录只出现以上八项。

科学约定：交流相量采用有效值，ABC 相序为 0°、−120°、+120°，默认 50 Hz / 24 V 相电压；记录仪表负载与电源内阻。星形/三角形的 √3 关系只在相应对称条件下核查；不对称星形断中线时从真实节点方程计算中点位移。灯泡使用标定到额定工作点的稳态热电阻经验模型，明确说明不包含热惯性和烧毁；不冒充实测灯泡曲线。

## 交付状态（v0.3.0，2026-11-14）

八项实验已进入主目录，选课后摆放对应器材，数据页只显示当前实验的操作、图表和记录。加入非线性小灯泡、可切换参考点的电位图、叠加/齐次性记录比较、两负载戴维南估参、最大功率曲线，以及星形/三角形交流测量。自由搭建保留旧能力，存档兼容旧版。

三相电源、仪表 AC/DC 模式和相序可以实际操作。负载电压相量图与测量表使用同一节点结果；断中线时显示真实负载相量变化。实验判定拒绝断电零响应、重复工作点和跨网络参数拼凑的记录。切换实验的撤销/重做同时恢复课程、器材和参考点。

按用户提供的走线参考图调整导线：无遮挡时使用沿插头切线出发的连续缓弧，短线轻微拱起；绕障路径采用更大的弯曲半径。每条候选曲线仍做机箱间隙检查，第三件器材移动/旋转会触发重算。此为几何走线，不是线缆动力学。

数值例证：同一有源网络下，100 / 500 / 2000 Ω 负载的实测功率分别约为 6.939 / 12.493 / 7.997 mW；星形负载 1000 / 500 / 2000 Ω 在断中线后，中点位移约为 9.069 V；三角形对称负载的线/相电流比约为 √3，不对称后不再满足统一 √3 比例。三相电源旋钮通过真实鼠标拖动使设定从 24 V 变为 45 V，随后恢复 24 V。
