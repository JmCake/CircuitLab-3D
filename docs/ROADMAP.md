## P0｜需求冻结与仓库规划（已完成）

**交付：** README、PRD、架构、阶段计划、教学实验清单和测试验收标准。确定项目名称、发布策略、MVP 最小器材及“代码建模优先”原则。规划阶段历史提交不包含功能代码。

**完成判据：** 文档一致、范围明确；每个后续阶段有对应验收点。

## P1｜3D 实验台与程序化器材原型（已实现）

**目标：** 在浏览器稳定展示真实实验室风格的场景。

**已交付：** Vite + React + TypeScript + R3F 工程；WebGL 2 能力检测；轨道相机、聚焦/重置；程序化实验桌、实验室空间与光照；电源、双数字表、电阻、电阻箱、变阻器、开关、电容、LED、灯泡、面包板的程序化几何与标签。

**验证：** 已从全景、电源近景、器材总览与不同设备角度截图检查；`npm run test:e2e` 可启动并渲染 WebGL 2 场景。

## P2｜三维编辑器与布线交互（已实现）

**目标：** 用户不编写代码即可搭出电路布局。

**已交付：** 器材库拖放/点击放置、选择、移动、旋转、删除、端子拾取、导线预览与吸附、插头、拔线、输入仲裁、撤销/重做、导线随器材移动、异常操作提示。

**验证：** 真实鼠标拖动接线柱成功建立导线；撤销/重做恢复；拖动旋钮时器材位置不变；空间相交不会建立电气连接。

## P3｜电路图核心与直流仿真（已实现）

**目标：** 计算通用基础直流电路，而不是只对预设实验返回硬编码读数。

**已交付：** 稳定元件/端口 ID、并查集节点合并、网表构建、节点分析、线性高斯消元、有限内阻电源、固定电阻、开关、电流表/电压表内阻、LED 非线性近似、仪表负载效应、奇异/短路/悬空/超量程诊断；纯算法测试。

**验证：** 35 个 Vitest 测试通过，详见 [ACCEPTANCE.md](ACCEPTANCE.md)。

## P4｜视觉同步与第一个完整实验（已实现）

**目标：** 从选器材到正确接线、调参、读取数据的闭环。

**已交付：** 仪表实时读数、开关机械动画、LED/灯泡结果驱动发光、电源数字显示、告警诊断、参数面板、数据快照、本地保存恢复、欧姆定律实验指导与 5/5 判定。

**验证：** E01 示范 6 根导线；电流表约 5.999 mA、电压表约 5.998 V；记录 R≈999.9 Ω。

## P5｜大学教学实验扩充（已实现核心）

**目标：** 从单实验扩展到入门电路实验集。

**已交付：** E02 串联分压、E03 并联分流、E04 KCL/KVL、E05 LED 限流、E06 RC；电阻箱、滑动变阻器、面包板、灯泡；数据导出 CSV、工程 JSON、自由搭建模式、帮助面板。

**验证：** 六组实验示范接线均通过统一求解器；E05 LED 点亮；E06 RC 曲线通过。

## P6｜电容暂态、精度与体验完善（部分实现）

**目标：** 覆盖电容充放电并提升稳定性。

**已完成：** RC 后向欧拉暂态、曲线显示、暂停/继续/重置、电容极性/耐压提示、元件模型说明、单元测试。

**未完成：** 实际集成显卡的帧率/内存基准、Firefox/Safari、移动端、屏幕阅读器、基于真实时间增量的完整墙钟同步、更多故障定位；详见 [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md)。

## 阶段依赖和优先级

P0 → P1 → P2 → P3 → P4 → P5 → P6。P1/P2 的三维交互与 P3 算法测试分层完成，进入 P4 前已统一电气连接并建立数值回归。
