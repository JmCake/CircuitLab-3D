# 开发路线图（只规划，不实施）

> 阶段按依赖顺序推进；各阶段仅列未来开发工作和完成判据，**均未开始实现**。不预设完成日期。

## P0｜需求冻结与仓库规划（当前）

**交付：** README、PRD、架构、阶段计划、教学实验清单和测试验收标准。确定项目名称、发布策略、MVP 最小器材及“代码建模优先”原则。仓库不包含功能代码。

**完成判据：** 文档一致、范围明确；每个后续阶段有对应验收点。

## P1｜3D 实验台与程序化器材原型

**目标：** 无电学求解时，先能在浏览器稳定展示真实实验室风格的场景。

**工作项：** 建立 React + TypeScript + R3F 工程；WebGL 2 能力检测；相机操作；实验桌、直流电源、固定电阻、开关、电表、接线端子、导线的代码建模规范；光照、材质、刻度字体；测试普通笔记本兼容性。

**验收：** 可旋转/缩放观察，器材外观清晰，坐标与端子位置一致；尚无仿真数值时 UI 明确标注未实现。

## P2｜三维编辑器与布线交互

**目标：** 用户可以不编写代码地搭出电路几何布局。

**工作项：** 元件库、拖放、选择、旋转、删除、端子拾取、导线吸附、撤线改线、输入仲裁、撤销重做、导线随器材移动、异常操作阻止。

**验收：** 任意接/断线操作都能生成正确结构化状态；导线几何相交不视为电气连接；连续操作不会破坏场景。

## P3｜电路图核心与直流仿真

**目标：** 能计算通用的基础直流电阻网络，而不是只对预设实验返回硬编码读数。

**工作项：** 稳定元件及端口 ID、拓扑建图、节点合并、网表构建、MNA 求解、理想/有限内阻电源、固定电阻、开关、仪表内阻模型、奇异矩阵/短路/断路诊断；纯算法单测。

**验收：** 欧姆定律、串联、并联、混联基础测试与解析结果一致；断线/非法参数给出明确状态；无错误的无穷大电流。

## P4｜视觉同步与第一个完整实验（MVP 发布候选）

**目标：** 完成一次从选器材到正确接线、调参、读取数据的闭环。

**工作项：** 仪表动态读数、开关实时状态、指示灯/LED 简化模型与标识、可视化告警、实验参数面板、数据快照、本地保存恢复；“欧姆定律实验”指导。

**验收：** 从空实验桌搭建回路，修改电压/电阻立即重算，断开开关显示正确响应，能保存并恢复，教学检查按拓扑和数值工作。

## P5｜大学教学实验扩充

**目标：** 从单实验扩展到完整的入门电路实验集。

**工作项：** 串并联、基尔霍夫定律、滑动变阻器、电阻箱、灯泡和更完善的 LED 模型；实验步骤管理、表格记录、结果导出、自由实验模式、可复用的实验数据定义。

**验收：** 预设实验与自由搭建均使用同一套求解器；数据可导出与重复加载；错误接线能定位到关键端口或网络。

## P6｜电容暂态、精度与体验完善（后续）

**目标：** 覆盖电容充放电和更高要求的实验稳定性。

**工作项：** 时间步进仿真、RC 暂态、曲线显示/测量工具、不同电脑性能测试、模型外观优化、无障碍交互、更多故障提示与用户测试。

**验收：** RC 曲线与解析解在约定容差内一致，用户可暂停/重置实验时间；模型与性能满足最终冻结的产品指标。

## 阶段依赖和优先级

P0 → P1 → P2 → P3 → P4 → P5 → P6。P1/P2 的三维交互可与 P3 算法单元测试分开开发，但进入 P4 前必须完成电气连接统一和数值回归。不要优先开发 AI 助教、后端用户体系或高成本装饰性动画。

## 首次正式开始开发时的顺序

先补充工程目录规范与测试框架，再从 P1 启动；每完成一阶段提交可运行演示、测试结果和阶段验收记录。规划阶段不产生空壳实现、假截图、假演示地址或未经验证的性能数据。
