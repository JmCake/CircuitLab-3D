# CircuitLab-3D｜三场景扩展方案（仅规划，暂不开发）

> 状态：**待定方案 / 未授权实施**。本文仅保留产品目标、技术方向、验收原则与开发顺序；不代表已实现，也不包含新增功能代码。原有自由实验台的实现、课程与数据不作改动。

## 总体定位

基于已有 CircuitLab-3D 大学电路虚拟实验室，未来扩展为三个相互独立、服务不同学习者的三维实验场景。场景通过简洁的顶部三段式切换进入：**自由实验台 / 面包板实验室 / 综合电路实验箱**。界面不堆积重复的说明和标签；以器材本身和实验操作传达功能。

| 场景 | 面向人群 | 实验方式 | 当前安排 |
| --- | --- | --- | --- |
| 自由实验台 | 大学电路理论学习者 | 选择和摆放独立仪表、元件，自主接线、测量、完成原有课程实验 | **保留现有成果，不重做** |
| 面包板实验室 | 电子爱好者、创客、电子技术初学者 | 在真实孔位布局的面包板插入元件引脚、跳线搭建电子电路 | **新增，暂不实施** |
| 综合电路实验箱 | 高校电工电子和电路分析实验课 | 操作固定的集成电路模块、接线柱、旋钮、仪表完成规范化实验 | **新增，暂不实施** |

## 视觉与体验原则

首先研究参考作品和真实器材，再确定效果，最后才进入编码。不能用粗糙几何体堆砌冒充高质量程序化 3D 建模，也不另造一套与现有项目割裂的视觉风格。保持 React + TypeScript + Three.js / React Three Fiber + WebGL 2 的技术方向；元件、仪器、实验箱与场景优先通过代码程序化建模。桌面端支持旋转、缩放、平移、聚焦和近距离观察；不同场景的相机视角及操作方式可独立优化。

面包板重点参考 BBRouter 等真实接线交互：孔位精密且正确分组，插孔能精确捕捉元件引脚与跳线，元件可以跨孔放置、移位和拔出；实际导电关系必须由插接和连线决定。可先比较 400 孔和 830 孔结构，避免在未确认外观、功能和性能之前锁死规格。

综合电路实验箱以用户提供的**真实实拍照片**为主要参考，不随意重新排列模块。外观方向：银色铝合金箱体、左侧高密度绿色 PCB、白色丝印电路图和密集金属端子、五组红色数码管、右侧集中旋钮与黑色收纳区。**初始状态不放置导线**，让学生自行接线。真实设备品牌/型号尚未确定，后续需先核对面板分区、端子数量与位置，以及电路图和控制器结构；无法核实的部分明确标示为教学近似，不能声称是逐元件原厂复刻。

## 系统架构

- 三个场景有各自的器材布置、相机视角、学习流程及独立存档；切换不能覆盖或清空其他场景，更不能损坏原自由实验台的存档。
- 共用既有电气元件与 Port ID、连线机制、MNA 电路求解、仪表反馈、撤销重做、数据记录基础设施；不另起一套重复且不兼容的物理仿真器。
- 面包板内部孔组等电位关系准确，电源轨分段符合选定的真实型号。元件插入后应自动生成对应电气连接，而不是仅仅绘制视觉位置。
- 实验箱内部不是装饰贴图：各端子对应明确的实际电路与元件关系。先支持已有线性直流课程实验，再评估受控源、负阻抗变换器和更复杂模块；按电学原理求解，不以随机数字或预设特效替代计算。

## 待决定事项

1. 两个新增场景的正式视觉方向与精细程度；优先验收单个真实器材的近景效果，而不是先制作整张演示页面。
2. 面包板具体规格、可插入元件范围、引脚与导线的交互规范。
3. 实验箱同款型号、厂家资料、面板电路图和要优先复刻的教学模块。
4. 三场景切换入口在现有 UI 中的最终位置与尺寸，以及是否允许跨场景移动电路作品。
5. 运行环境、普通笔记本集显的性能目标和自动/人工验收方式。

## 将来经授权后才执行的建议顺序

1. **设计验证**：收集并分析参考器材，确认三维比例、建模细节、镜头视角与交互体验；真实项目内验证效果，不再用脱离代码的低质量概念预览替代。
2. **面包板实验室**：实现真实插接拓扑、器材/跳线操作、电学计算、教学例题与独立存档；从简单 LED 限流电路开始验收。
3. **综合实验箱**：先按原图精确程序化建模，再依照可靠电路图逐个接入内部电路，验证接线与仪表读数。
4. **集成回归**：完整检查原自由实验台的所有教学实验、存档、操作、导线避障与计算结果；对两个新场景进行浏览器视觉测试和性能测试。
5. **审查与发布**：满足真实视觉、交互、电学三类验收标准后才合并与发布；测试不通过时不可宣称完成。
