# CircuitLab-3D｜单件实验仪器程序化 3D 建模提示词

> 与 `MASTER_PROJECT_PROMPT.md` 联用。本文件用于未来**逐一**打磨电源、电表、开关、电阻等模型。当前只保存提示词，不实施代码。

## 通用可复制提示词

你是一名具有电子仪器产品设计经验的 Three.js / React Three Fiber 3D 技术美术工程师。请基于仓库的技术架构与现有组件体系，为 **【仪器名称】** 制作高辨识度、可操作、可维护的程序化三维模型。

**使用前必须先明确参数**：
- 器材名称：【例如：可调直流稳压电源】
- 大致外形尺寸：【长 × 宽 × 高，单位统一；无法确定时以合理教学仪器比例为暂定，并标注为估计】
- 必要结构：【外壳、底脚、前后面板、屏幕/指针、旋钮、开关、接线柱、刻度/文字】
- 可操作件：【例如：电压旋钮、总电源开关、接线柱】
- 电气端口：【稳定 portId、用途、极性、额定量程及相对于器材原点的局部坐标】
- 状态数据：【例如：setVoltage、enabled、measuredCurrent；状态来自领域层，而非在 Mesh 内自行求解】
- 视角需求：【全景可辨认，45 度斜角/正面特写可查看关键控件】
- 验收场景：【台面上实际放置并接线的构图】

### 一、几何和结构要求

禁止把整台器材简化成贴了文字的单个方块。必须先列出分件结构树，例如：
- 根节点 Group：统一的模型局部原点、比例、变换矩阵与组件 ID
- 壳体：圆角、厚度、前后盖、散热缝、分型线、底脚等
- 前面板：略微凹陷/凸起的结构、控制区和测量区
- 屏幕/刻度：可读数字与功能标识；使用清晰的 CanvasTexture、几何构字或合适的 HTML 叠层；需考虑缩放时可读性
- 旋钮/拨杆：独立转轴和枢轴、刻度定位、旋转范围
- 端子：绝缘座、金属导电口、红黑颜色区分、合理外凸深度及拾取范围
- 辅助细节：螺钉、铆钉、压纹、灯罩、导轨等，优先少量真正提升辨识度的细节

几何可用 Box、Cylinder、Sphere、Torus、Lathe、Extrude、Tube 与自定义 Shape/BufferGeometry 等组合，复用缓存；所有部件都需要有确定的相对位置及实际厚度，避免悬浮和穿插。

### 二、材质与灯光要求

- 外壳：喷涂金属或磨砂塑料，低饱和灰白色，适当 roughness。
- 接线柱：铜色/镀镍金属与红黑绝缘套，金属度和粗糙度应与塑料区分。
- 显示区：轻微内凹边框、深色玻璃及适量屏幕自发光；亮度不要抹掉数字。
- 旋钮：适当摩擦纹理或几何刻槽，让方向角度可以视觉辨认。
- 光照：以一个主要柔光方向定义体积，环境光/补光控制暗部，接触阴影显示物体与台面的接触；不使用夸张的科幻霓虹。
- 以“真实高校教学实验室器材的精致数字孪生模型”为美术目标，不追求游戏化夸饰。

### 三、交互与数据边界

- 射线检测命中控件时返回明确标识，例如 `componentId/controlId/portId`，而不是根据材质名推断。
- 端口拾取半径可略大于可见端子的几何范围，但必须反馈高亮，不允许错误接中相邻端子。
- 在拖拽、旋转器材与操作旋钮之间实行输入优先级，避免相机旋转误触发。
- 旋钮动作只向外部传递参数修改事件；电表数字只能显示外部传入的结果快照，不能随机生成。
- 元件整体移动或旋转后，端口世界位置通过矩阵换算得到，并可用于导线端点更新。
- 明确暴露只读几何元信息及可配置的外观参数，方便未来复用多个实例。

### 四、性能和输出要求

- 保持清晰模块命名，统一单位；材质/几何缓存复用，不在 `useFrame` 内不断创建几何、纹理或数组。
- 注意后处理成本、阴影、锯齿、拾取物体数量，避免在普通集成显卡设备上因装饰细节严重卡顿。
- 得到阶段实施授权后，先交“零件层级表、参数和端口规划”，再实现模型、展示与交互；必要时在浏览器中检查**整体视角、正面特写、45° 特写、旋钮/端口操作状态**。
- 没有实际运行测试时，必须明确未验证；不要发明性能数据、截图或仓库提交。
- 如果当前阶段没有获准实施，仅整理具体设计方案，不输出未经请求的功能实现。

## 专项模板：可调直流稳压电源

请基于上述规则为大学电路基础实验制作 **可调直流稳压电源** 的代码模型，满足：
1. 外形为桌面式金属/塑料仪器机箱，长方体主体带圆角、底脚、边缘分型线与侧面散热区域；外形宽大于高，深度足以稳定摆放。
2. 前面板有独立的电压、电流显示区；显示字形清晰，区分 V 和 A 单位。所有数值由属性传入并注明设定值或测量值。
3. 至少有输出正极（红色）和负极（黑色）香蕉插孔/接线柱。各有金属导电部位、绝缘座与单独可交互的 `portId`；端子不能只是平面红黑圆点。
4. 电压旋钮具有独立枢轴、方向指示、刻度环、阻尼平滑效果；调整行为对外发出 `onSetVoltage` 等参数事件，不自行计算电路。
5. 具有电源开关和状态灯；灯光状态区分“设备供电开启”和“外部回路有电流”两回事。
6. 正常视角识别为一台真实直流实验电源，放大后能检查屏幕、旋钮、端口的分件结构；不依赖 GLB/FBX/OBJ 或外部照片贴图。
7. 给出模型尺寸与局部坐标表，为后续连线系统提供稳定接点坐标与拾取范围。

**验收重点：** 仪表不像贴图纸盒、端子能准确选中、旋钮转动中心正确、数字可读、材质分层明确、器材与台面自然接触。后续模型开发必须复用这套组件规范。
